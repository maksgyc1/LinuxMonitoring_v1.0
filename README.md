# Проект: Linux Monitoring v1.0  

## Задание  

Необходимо разработать набор bash-скриптов для мониторинга и анализа состояния Linux-системы.  

### Требования к проекту:  

1. **Сбор системной информации**  
   - Получить hostname, timezone, имя пользователя, ОС и версию, текущую дату и аптайм.  
   - Определить IP-адрес, маску подсети и gateway.  
   - Собрать информацию о RAM (всего/занято/свободно) и дисковом пространстве root-раздела.  
   - Добавить возможность сохранения отчёта в файл с именем по текущему времени.  

2. **Настройка визуализации вывода**  
   - Реализовать вывод с настройкой цвета текста и фона через параметры.  
   - Сделать конфигурацию цветовой схемы через отдельный конфигурационный файл с параметрами по умолчанию.  

3. **Исследование файловой системы**  
   - Подсчитать количество папок и файлов.  
   - Классифицировать файлы по типам (.conf, .txt, .exe, .log, архивы, символические ссылки).  
   - Определить топ-5 папок по размеру и топ-10 файлов по размеру (с указанием пути, размера и типа).  
   - Найти топ-10 исполняемых файлов по размеру и вычислить для них хеш MD5.  
   - Вывести время выполнения скрипта.
